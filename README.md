# Captura para Mac

Capturas de ventanas y áreas, OCR local, anotaciones, blur, fondos y captura con scroll.

Este repositorio contiene las descargas y el canal público de actualizaciones. El código fuente no forma parte de este repositorio.

## Descargar

[Descargar la última versión](https://github.com/arenter1/captura-updates/releases/latest)

Requiere **Mac con chip Apple y macOS 14 o posterior**.

Antes de la primera apertura, verifica la autenticidad del paquete por un canal independiente de esta página. Para la entrega familiar, utiliza AirDrop o USB desde la Mac que preparó la versión y compara su SHA-256 recibido directamente del autor. Un hash obtenido únicamente de esta misma página no protege frente a una sustitución de todo el alojamiento.

1. Obtén el ZIP, verifica esa referencia independiente y descomprímelo.
2. Copia **Captura.app** a Aplicaciones antes de abrirla. Si ya tienes Captura, cierra la versión anterior antes de reemplazarla.
3. La app usa firma local y no está notarizada por Apple. macOS puede pedir que autorices su apertura en **Ajustes del Sistema → Privacidad y seguridad**. Autoriza únicamente el paquete que descargaste de este repositorio.
4. Concede a Captura el permiso de **Grabación de pantalla** y vuelve a abrir la app cuando macOS lo solicite.

## Actualizar desde Captura

Desde la versión 0.12.0, abre **Ajustes → Actualizaciones → Buscar actualizaciones**. También aparece en el menú de Captura y en **Más**. La app puede buscar versiones nuevas diariamente; tú decides cuándo instalarlas. Si tenías una versión anterior a 0.12.0, instala esta primera versión manualmente una vez.

Sparkle verifica la firma del canal y del paquete antes de extraerlo. La clave privada de distribución no se publica. No necesitas una cuenta de Sparkle ni iniciar sesión en GitHub para descargar o actualizar.

Las capturas, el OCR y la edición se procesan en tu Mac. La búsqueda de versiones contacta con GitHub para descargar información y paquetes de actualización. No sube tus capturas. Al cambiar la firma local entre versiones, macOS puede solicitar renovar el permiso de pantalla.
